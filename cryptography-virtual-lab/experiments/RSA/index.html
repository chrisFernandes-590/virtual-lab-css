RSA Encryption and Decryption

Virtual Cryptography Laboratory · Generate a key pair, encrypt a message, decrypt it, and inspect the mathematics behind each step.

Aim

To understand and simulate RSA public-key cryptography by generating an RSA key pair and using it to encrypt and decrypt messages.

Objectives

  • Generate RSA public and private keys.
  • Understand the roles of p, q, n, φ(n), e, and d.
  • Encrypt a message using the public key.
  • Decrypt the ciphertext using the private key.
  • Observe how changing the key parameters changes the ciphertext.

RSA Theory

RSA is a public-key cryptosystem. Two related keys are used: a public key for encryption and a private key for decryption.

Choose primes p and q
n = p × q
φ(n) = (p − 1)(q − 1)
Choose e such that 1 < e < φ(n) and gcd(e, φ(n)) = 1
Find d such that e × d ≡ 1 (mod φ(n))
Public key = (e, n)
Private key = (d, n)

For a message represented by an integer m with 0 ≤ m < n:

Encryption: c = me mod n
Decryption: m = cd mod n

Educational note: this browser simulation intentionally uses small/toy RSA parameters so the arithmetic can be visualized. It is not suitable for protecting real data.

Step-by-step Procedure

  1. Enter two distinct prime numbers p and q, or click Generate Example Keys.
  2. Compute n = p × q.
  3. Compute Euler's totient φ(n) = (p−1)(q−1).
  4. Choose a valid public exponent e coprime to φ(n).
  5. Compute the private exponent d, the modular inverse of e modulo φ(n).
  6. The public key is (e,n); the private key is (d,n).
  7. Enter a short message and click Encrypt. Each UTF-8 byte is converted to an integer and encrypted.
  8. Click Decrypt to recover the original bytes and message.
  9. Use Reset to repeat the experiment with different values.

Expected Observation

The public key can be used to transform the message into ciphertext. The corresponding private key reverses that transformation, returning the original message.

Original message → UTF-8 bytes → RSA encryption → Ciphertext → RSA decryption → Original bytes → Original message

Evaluation Questions

  1. What is the purpose of selecting two prime numbers in RSA?
  2. How is φ(n) calculated for the two-prime RSA setup?
  3. What mathematical relationship must hold between e and φ(n)?
  4. How is d obtained from e and φ(n)?
  5. Which key is used for encryption in this experiment and which key is used for decryption?
  6. Why must the message integer be smaller than n?
