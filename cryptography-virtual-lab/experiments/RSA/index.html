1. Introduction to Public-Key Cryptography

Introduced by Ron Rivest, Adi Shamir, and Leonard Adleman in 1977, RSA is an asymmetric cryptosystem. Unlike symmetric ciphers (like AES or DES) where sender and receiver must share a confidential key over a secure channel, RSA operates using a mathematically linked key pair:

Public Key (e, n)

Published openly to the world. Anyone can use (e, n) to encrypt a confidential message or verify a digital signature.

Private Key (d, n)

Kept strictly secret by the receiver. Only the holder of d can decrypt ciphertexts or generate valid digital signatures.

📐

2. Mathematical Foundations & Key Generation

The mathematical security of RSA relies on the trapdoor one-way permutation concept:

Step 1: Select Primes
Choose two distinct large prime numbers p and q.

Step 2: Compute Modulus n
n = p × q
The length of n in bits represents the key size (e.g., 2048 or 3072 bits).

Step 3: Compute Euler's Totient φ(n)
φ(n) = φ(p) × φ(q) = (p − 1)(q − 1)
φ(n) counts the number of positive integers up to n that are coprime to n.

Step 4: Choose Public Exponent e
Select an integer e such that 1 < e < φ(n) and gcd(e, φ(n)) = 1.
Standard industry values include e = 65537 (216 + 1, Fermat prime F4) for fast exponentiation.

Step 5: Compute Private Exponent d
Calculate d as the modular multiplicative inverse of e modulo φ(n) using the Extended Euclidean Algorithm:
e × d ≡ 1 (mod φ(n)) ⇔ d ≡ e−1 (mod φ(n))

3. Encryption, Decryption & Proof of Correctness

Encryption Process

Convert plaintext into integer m where 0 ≤ m < n. Compute ciphertext c:

c = me mod n

Decryption Process

Using the secret exponent d, recover message integer m:

m = cd mod n

Mathematical Proof of Decryption (cd ≡ m mod n)

Since e · d ≡ 1 (mod φ(n)), there exists an integer k such that e · d = 1 + kφ(n) = 1 + k(p − 1)(q − 1).

cd ≡ (me)d ≡ med ≡ m1 + k(p−1)(q−1) (mod n)

Case 1 (gcd(m, n) = 1): By Euler's Totient Theorem, mφ(n) ≡ 1 (mod n).
med = m · (mφ(n))k ≡ m · (1)k ≡ m (mod n).

Case 2 (gcd(m, n) > 1): Using Fermat's Little Theorem and the Chinese Remainder Theorem (CRT), med ≡ m (mod p) and med ≡ m (mod q), guaranteeing med ≡ m (mod pq).
🛡️

4. Textbook RSA vs Modern RSA with OAEP

This virtual lab demonstrates Textbook RSA, where byte values are directly exponentiated. In real-world security systems, unpadded textbook RSA is vulnerable:

⚠️ Textbook RSA Weaknesses
  • Deterministic: Identical plaintexts produce identical ciphertexts.
  • Multiplicative Homomorphism: (m1)e · (m2)e ≡ (m1m2)e (mod n), enabling ciphertext tampering.
  • Chosen-Ciphertext Attack (CCA2): Attackers can query decryptions of c · re mod n.
✅ Modern RSA-OAEP (PKCS#1 v2.2)
  • Probabilistic Padding: Optimal Asymmetric Encryption Padding injects cryptographic randomness and hash functions.
  • IND-CCA2 Secure: Prevents malleability and structural relation attacks.
  • Standard Key Size: Minimum 2048-bit or 3072-bit keys to defeat General Number Field Sieve (GNFS) factorization.

Viva Voce & Analytical Questions

1. Why must p and q be kept secret once keys are generated? ▼
If an attacker obtains p and q, they can immediately calculate φ(n) = (p−1)(q−1). Using the public exponent e, they can calculate the private key d ≡ e−1 (mod φ(n)) via the Extended Euclidean Algorithm, breaking the system completely.
2. Why is e = 65537 favored over small exponents like e = 3? ▼
65537 = 216 + 1 has a binary representation with only two 1s (10000000000000001), requiring only 17 modular multiplications. It is large enough to resist Håstad's broadcast attack and Coppersmith's short pad attack which compromise e = 3.
3. What is the difference between asymmetric and symmetric encryption? ▼
Symmetric encryption (e.g. AES) uses a single shared secret key for both encryption and decryption. Asymmetric encryption (e.g. RSA) uses a mathematically bound pair: a public key for encryption and a private key for decryption.
4. What happens if message integer m ≥ n? ▼
Modular reduction operates modulo n. If m ≥ n, m mod n produces an alias in ℤn, causing irreversible information loss during decryption because multiple distinct messages map to the same ciphertext.
